# Breakout_Room_3 Navigation Project

## Description
This is a dart/flutter project which showcases a list of tech products, with their description, rating and price.
One is able to click through that list of products and open one of them, to navigate to a single dedicated product 
screen. 
one can also navigate back to thelist of the products

## Verification and Launch
- Open your IDE or Android Studio
- Plug in your physical device or Start a Mobile Emulator
- Make sure the emalator is listed by running `flutter devices`
- Start/Run the project by:
```
flutter run -t lib/main.dart
```
- Let the build happen and then navigate through the app
